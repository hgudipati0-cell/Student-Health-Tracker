# STUDENT HEALTH TRACKER 
This project uses Python to collect data of students' habits and health to outline and analyze trends over time 

# FEATURES USED 
- Daily health logging
- Use of CSV data storage 
- Data visualization 

# Technologies and Libraries used 
- Python 
- Pandas
- Matplotlib

# Applications
-tracks student health care and habits 
-allow students to visualize their health and habits 
-collects data to output average conclusions
